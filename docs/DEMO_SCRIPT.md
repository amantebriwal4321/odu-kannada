# Demo script

About 2 to 3 minutes. No names in the voiceover. Record on a phone if you can, then a short desktop cut of the archive.

## 0:00 Open

Show the home screen.

"This is Odu. It reads a Kannada page: a notice, a land record, a letter. The photo stays on one side. The text stays editable on the other."

Point at the status line.

"No API key is set. The pill says the browser and the offline explainer are doing the work."

## 0:20 Sample

Tap Pension circular.

"These samples are fictional, and the text is already in the app, so a demo does not wait on a provider."

Scroll the Kannada text. Change one word, then change it back.

"If a real scan misses a word, you fix it here."

## 0:45 Explain

Point at the simple Kannada, then the English, then the chips.

"Plain Kannada, plain English, and the bits you usually hunt for: the last date, the rupee amount, the office, what you have to do."

## 1:05 Listen

Tap Read summary. Let a few seconds play. Tap Stop.

"That was the phone voice. With a Sarvam key, the same button asks Bulbul for Kannada speech."

## 1:20 Ask

Tap the chip `ಕೊನೆಯ ದಿನಾಂಕ ಯಾವುದು?`

"The question is Kannada, so the answer is Kannada."

Then type `what should I do?` and tap Ask.

"Same page, English question, English answer."

## 1:45 Archive

Open Archive. Search `pension`. Open the row.

"It is saved in this browser. Search checks the Kannada text and the English summary, and it ignores zero width joiners that show up in Kannada Unicode."

Tap Download .md.

## 2:10 Close

Back to Read. Point at Take photo.

"A photo from the gallery takes the same path. Sarvam digitises if that key is set, then Gemini vision, then Tesseract with the Kannada model in the browser. Explain follows Gemini, then Sarvam chat, then the offline extractor. The sample you just saw does not need any of them."
